# Notifications Specification

## Purpose

Системные уведомления о новых сообщениях: доставка через Tauri-плагин или
Web Notification API, превью текста сообщения, корректная работа в зашифрованных
комнатах.

## Requirements

### Requirement: Системные уведомления в Tauri
Система SHALL отправлять системные уведомления через `tauri-plugin-notification`,
с фолбэком на Web Notification API. Отправка идёт по флагу `showNotifications`;
web-fallback защищён `try/catch`. Клик по уведомлению в Tauri desktop-плагине не
отдаётся — `onClick` работает только в браузере.

#### Scenario: Новое сообщение
- **WHEN** поступает новое сообщение и уведомления включены
- **THEN** показывается системное уведомление

#### Scenario: Запрос разрешения
- **WHEN** пользователь нажимает Enable в настройках уведомлений
- **THEN** разрешение запрашивается через Tauri-плагин

### Requirement: Превью текста сообщения
Система SHALL формировать превью текста уведомления через `extractMessagePreview`:
текст обрезается до 100 символов + «…»; для медиа — тип (`Sent an image` и т.д.);
для зашифрованных — `Sent an encrypted message`. Body уведомления:
`{username}: {messagePreview}`.

#### Scenario: Текстовое сообщение
- **WHEN** приходит текстовое сообщение
- **THEN** body уведомления содержит `username: <превью текста>`

#### Scenario: Медиа-сообщение
- **WHEN** приходит изображение/видео/аудио/файл
- **THEN** body содержит тип сообщения, например `Sent an image`

### Requirement: Уведомления для зашифрованных комнат
Система SHALL отправлять уведомление для зашифрованных событий после
`MatrixEventEvent.Decrypted` (с фолбэк-таймером 5 с), а не сразу по
`RoomEvent.Timeline`. Текст `m.bad.encrypted` — `Unable to decrypt message`.

#### Scenario: Зашифрованное сообщение расшифровано
- **WHEN** зашифрованное событие успешно расшифровано
- **THEN** уведомление отправляется с реальным текстом превью

#### Scenario: Расшифровка не успела
- **WHEN** событие не расшифровано за 5 секунд
- **THEN** отправляется уведомление с текстом `Unable to decrypt message`
