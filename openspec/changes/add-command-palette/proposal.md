# Proposal: add-command-palette

**Задача:** [schadin/harrier-project#58](https://github.com/schadin/harrier-project/issues/58)

## Why

Навигация в Harrier построена вокруг мыши и сайдбара: переход в комнату, поиск
пользователя, открытие настроек или смена статуса требуют нескольких кликов.
Command Palette — стандарт де-факто для десктопных приложений (VS Code, Slack,
Discord, Linear); его отсутствие снижает восприятие Harrier как «настоящего»
десктопного клиента. Это относительно небольшая задача с большим UX-эффектом,
которая к тому же отличает Harrier от Cinny.

## What Changes

- Новое модальное окно Command Palette, открываемое по Ctrl/Cmd+P из любого
  экрана приложения; закрытие по Esc, полное управление с клавиатуры
  (стрелки + Enter).
- Шорткат палитры (Ctrl/Cmd+P) работает независимо от текущей раскладки
  клавиатуры и языка ввода.
- Команда «Непрочитанные чаты»: фильтр палитры по непрочитанным комнатам с
  показом первого непрочитанного сообщения каждой комнаты.
- Поиск и переходы: комнаты (по названию, алиасу, ID), пользователи
  (по имени, MXID), пространства и лобби, разделы настроек.
- Выполнение команд: смена статуса (пресеты presence), mute комнаты,
  mark all as read, logout, быстрое создание комнаты / DM, список
  непрочитанных чатов.
- Fuzzy-поиск с подсветкой совпадений, группировка результатов по категориям
  (комнаты, люди, пространства, настройки, действия).
- История последних действий в палитре.
- UX-детали: индикатор загрузки для асинхронных действий, пустое состояние
  с подсказками.
- После перехода в чат из палитры фокус ставится в поле ввода сообщения;
  отдельный шорткат Ctrl/Cmd+Shift+M фокусирует поле ввода из любого места.

Глобальный хоткей на уровне ОС (через Tauri global-shortcut) **не входит** в
объём этого изменения — палитра открывается только внутри окна приложения.

## Capabilities

### New Capabilities

- `command-palette`: модальная палитра команд с fuzzy-поиском по комнатам,
  пользователям, пространствам и настройкам, выполнением действий (статус,
  mute, mark all read, logout, создание комнаты/DM), историей действий и
  полным управлением с клавиатуры.

### Modified Capabilities

- `presence`: добавляется требование о доступности смены статуса (выбор
  пресета) из Command Palette — существующий механизм presence переиспользуется,
  нового протоколного поведения не появляется.

## Impact

- **Код:** форк веб-клиента (`cinny/` внутри `desktop/`): новые компоненты
  палитры (React + vanilla-extract), глобальный обработчик Ctrl/Cmd+P,
  интеграция с существующей навигацией (react-router-dom), списками комнат,
  поиском пользователей (matrix-js-sdk), настройками и presence.
- **Зависимости:** fuzzy-поиск — либо существующая библиотека в дереве
  зависимостей Cinny, либо новая лёгкая зависимость (например, fuse.js) —
  решение фиксируется в design.md.
- **i18n:** новые строки интерфейса (домен `delivery`).
- **Десктоп-обёртка:** изменений в Tauri/Rust-коде не требуется.
- **Инвариант протокола:** все действия палитры используют только существующие
  механизмы Matrix через matrix-js-sdk (события, presence, room state).
