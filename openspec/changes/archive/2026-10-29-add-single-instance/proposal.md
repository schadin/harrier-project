## Why

При повторном запуске Harrier создаётся второй процесс со своим окном: у пользователя появляется дубликат клиента с отдельной сессией, а под Niri второе бездекорное окно «прилипает» поверх основного без возможности сфокусировать уже открытое. Повторный запуск должен активировать уже работающее приложение.

При этом жёстко зафиксированное поведение не всех устраивает: пользователю может быть нужно держать два независимых экземпляра (разные учётные записи, разные сессии), и переход на единственный экземпляр ломает такой сценарий. Поэтому перехват повторного запуска делается настройкой, а не безусловным правилом.

## What Changes

- В настройках приложения появляется переключатель «Single instance», доступный только в десктопной версии.
- **По умолчанию переключатель выключен**: каждыйый запуск Harrier создаёт отдельный экземпляр приложения со своим окном — поведение, как до появления перехвата.
- Если переключатель включён, повторный запуск не создаёт новый процесс и новое окно: приложение активирует уже запущенный экземпляр.
- Существующее окно при этом показывается (в том числе если оно свёрнуто или скрыто) и получает фокус — тем же способом, что и по клику на трей.
- Изменение переключателя не требует перезапуска уже работающего приложения: новое значение применяется при следующем запуске.
- Функция доступна на всех десктопных платформах (Windows, Linux, macOS); веб-версия не затрагивается.

### Modified Capabilities

- `desktop-integration`: добавляется требование «Один экземпляр приложения» — переключатель «Single instance» (по умолчанию выключен), который либо активирует уже запущенное окно вместо создания второго процесса, либо разрешает запуск отдельного экземпляра.

## Impact

- `desktop/src-tauri/Cargo.toml` — зависимость `tauri-plugin-single-instance`.
- `desktop/src-tauri/src/lib.rs` — условная регистрация плагина и новая команда настройки.
- `desktop/src-tauri/src/settings.rs` _(новый)_ — чтение и запись флага в файле каталога данных приложения, вычисление пути по образцу `migrate.rs`.
- `desktop/src-tauri/src/tray.rs` — доступ к существующей функции показа окна из колбэка плагина.
- `desktop/cinny/src/app/state/settings.ts` — новое поле `singleInstance` с значением по умолчанию `false`.
- `desktop/cinny/src/app/features/settings/general/General.tsx` — переключатель в секции Desktop.
- `desktop/cinny/src/app/utils/desktop.ts` — обёртка над новой tauri-командой.
- Патч ребрендинга не затрагивается (правки только в Rust-части обёртки и в секции Desktop настроек).
- Документация: `openspec/specs/desktop-integration/spec.md`, при необходимости `desktop/README.md`.
