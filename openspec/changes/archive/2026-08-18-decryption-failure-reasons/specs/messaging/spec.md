## ADDED Requirements

### Requirement: Причина неудачной расшифровки в ленте
Система SHALL отображать вместо общей заглушки «Unable to decrypt message»
локализованное сообщение о причине неудачной расшифровки, определённой по
`MatrixEvent.decryptionFailureReason` (`DecryptionFailureCode`). Если причина
отсутствует или неизвестна (`null` / `UNKNOWN_ERROR`), система SHALL показывать
общий текст о невозможности расшифровать сообщение.

#### Scenario: Ключ сессии ещё не получен
- **WHEN** событие не расшифровано с причиной `MEGOLM_UNKNOWN_INBOUND_SESSION_ID`
- **THEN** отображается текст «Ключ для сообщения ещё не получен»
- **AND** сообщение остаётся в состоянии ожидания ключа

#### Scenario: Ключ удержан из-за неверифицированного устройства
- **WHEN** событие не расшифровано с причиной `MEGOLM_KEY_WITHHELD_FOR_UNVERIFIED_DEVICE`
- **THEN** отображается текст «Отправитель не выдаёт ключ: устройство не верифицировано»

#### Scenario: Историческое сообщение без доступа к бэкапу
- **WHEN** событие не расшифровано с причиной `HISTORICAL_MESSAGE_NO_KEY_BACKUP`
  или `HISTORICAL_MESSAGE_BACKUP_UNCONFIGURED`
- **THEN** отображается текст «Историческое сообщение, ключ недоступен — требуется
  настроить или восстановить бэкап ключей»

#### Scenario: Неизвестная причина
- **WHEN** событие не расшифровано, а `decryptionFailureReason` равен `null`
  или `UNKNOWN_ERROR`
- **THEN** отображается общий текст о невозможности расшифровать сообщение

### Requirement: Действие по причине неудачной расшифровки
Система SHALL предлагать пользователю контекстное действие (CTA) в зависимости
от причины неудачной расшифровки: «Запросить ключ» для причин, когда ключ может
быть получен позже; «Верифицировать устройство» для
`MEGOLM_KEY_WITHHELD_FOR_UNVERIFIED_DEVICE`; «Настроить/восстановить бэкап» —
для исторических причин вида `HISTORICAL_MESSAGE_*`. Для причин, не имеющих
эффективного действия, CTA SHALL отсутствовать.

#### Scenario: Запрос ключа для ожидаемого ключа
- **WHEN** событие не расшифровано с причиной `MEGOLM_UNKNOWN_INBOUND_SESSION_ID`
- **THEN** рядом с причиной отображается действие «Запросить ключ»

#### Scenario: Переход к верификации устройства
- **WHEN** событие не расшифровано с причиной `MEGOLM_KEY_WITHHELD_FOR_UNVERIFIED_DEVICE`
- **THEN** отображается действие «Верифицировать устройство»
- **AND** действие открывает настройки устройств

#### Scenario: Переход к бэкапу ключей
- **WHEN** событие не расшифровано с причиной `HISTORICAL_MESSAGE_NO_KEY_BACKUP`
  или `HISTORICAL_MESSAGE_BACKUP_UNCONFIGURED`
- **THEN** отображается действие «Настроить/восстановить бэкап»
- **AND** действие открывает панель резервного копирования

#### Scenario: Нет действия для необратимой причины
- **WHEN** событие не расшифровано с причиной без эффективного действия
  (например, `SENDER_IDENTITY_PREVIOUSLY_VERIFIED`)
- **THEN** отображается только причина без CTA
