# messaging Delta

## MODIFIED Requirements

### Requirement: Авто-восстановление бэкапа после перезапуска
Система SHALL автоматически восстанавливать бэкап ключей после запуска клиента
без ручного ввода recovery key/passphrase, если ключ восстановления доступен в
локальном хранилище. Восстановление SHALL выполняться через
`bootstrapSecretStorage({})` + `loadSessionBackupPrivateKeyFromSecretStorage()`
и `restoreKeyBackup()`, а прогресс отображаться в существующем
`backupRestoreProgressAtom`. Авто-восстановление SHALL быть ненавязчивым:
выполняется одна попытка за сессию; при ошибке или отсутствии бэкапа повторные
попытки на sync-циклах не запускаются. Повторная попытка выполняется только по
значимому событию — появлению `KeyBackupDecryptionKeyCached`.

#### Scenario: Авто-восстановление при запуске
- **WHEN** клиент запускается, а ключ восстановления доступен в локальном
  хранилище
- **THEN** система автоматически инициализирует ключ SSSS и запускает
  `restoreKeyBackup()`
- **AND** пользователь не запрашивается о вводе recovery key/passphrase

#### Scenario: Восстановление по событию появления ключа
- **WHEN** после логина приходит событие `KeyBackupDecryptionKeyCached`
- **THEN** система выполняет `restoreKeyBackup()` с прогрессом в
  `backupRestoreProgressAtom`

#### Scenario: Отсутствие цикла при ошибке или отсутствии бэкапа
- **WHEN** авто-восстановление завершилось ошибкой либо бэкап отсутствует, и
  далее происходят новые переходы sync в `SYNCING`
- **THEN** повторные попытки восстановления не запускаются

#### Scenario: Повтор после появления ключа бэкапа
- **WHEN** ранее провальная (или пропущенная) попытка была совершена и приходит
  `KeyBackupDecryptionKeyCached`
- **THEN** выполняется ровно одна новая попытка восстановления

#### Scenario: Исторические сообщения расшифрованы после перезапуска
- **WHEN** ключ бэкапа доступен после перезапуска и восстановление выполнено
- **THEN** исторические и пропущенные сообщения расшифровываются через
  точечную загрузку ключей (`PerSessionBackupDownloader`)
- **AND** не требуется ручной ввод recovery key/passphrase
