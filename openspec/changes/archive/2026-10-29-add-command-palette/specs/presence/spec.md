# Delta Spec: presence

## ADDED Requirements

### Requirement: Смена статуса из Command Palette

Система SHALL предоставлять смену кастомного статуса через Command Palette:
команда смены статуса предлагает объединённый список стандартных и кастомных
пресетов и применяет выбранный через существующий механизм
`setCustomStatusWithTime` (Matrix presence `status_msg`). Нового протоколного
поведения не вводится.

#### Scenario: Применение пресета из палитры

- **WHEN** пользователь выбирает в Command Palette команду смены статуса и
  пресет
- **THEN** статус публикуется через `presence.status_msg`, отображается в
  карточках и отмечается галочкой в меню кнопки профиля
