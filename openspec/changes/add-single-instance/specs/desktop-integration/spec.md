## ADDED Requirements

### Requirement: Один экземпляр приложения
Система SHALL при повторном запуске на десктопе не создавать второй процесс и
второе окно: уже запущенный экземпляр перехватывает запуск и активирует своё
главное окно — снимает сворачивание, показывает окно и передаёт ему фокус
(тем же способом, что и показ из трея). Требование распространяется на Windows,
Linux и macOS; веб-версия не затрагивается.

#### Scenario: Повторный запуск при работающем приложении
- **WHEN** пользователь запускает Harrier, когда приложение уже запущено
- **THEN** новое окно не создаётся, а существующее окно показывается и
  получает фокус

#### Scenario: Повторный запуск при свёрнутом или скрытом окне
- **WHEN** главное окно запущенного экземпляра свёрнуто или скрыто (например,
  закрыто через трей) и пользователь запускает Harrier снова
- **THEN** окно разворачивается, показывается и получает фокус

#### Scenario: Первый запуск
- **WHEN** приложение ещё не запущено
- **THEN** перехвата не происходит и создаётся единственное главное окно
