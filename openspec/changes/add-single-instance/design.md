## Context

Десктопная обёртка (`schadin/harrier-desktop`, Tauri v2) при повторном запуске
создаёт полноценный второй процесс со своим окном и сессией. Показать уже
открытое окно умеет трей: `tray.rs::show_main_window` делает
`unminimize` + `show` + `set_focus` для окна `"main"`. Фронтенд и подмодуль
`cinny` при этом не затрагиваются — задача полностью в Rust-части.

Инвариант протокола не затрагивается. Веб-сборка (Pages) работает без
`src-tauri` и остаётся без изменений.

## Goals / Non-Goals

**Goals:**
- Второй запуск не создаёт новый процесс/окно, а активирует уже работающее.
- Поведение активации совпадает с показом из трея (один код, не две реализации).
- Работает на Windows, Linux и macOS.

**Non-Goals:**
- Реализация «сворачивания в трей» и фонового режима — отдельная задача.
- Передача аргументов/файлов из второго запуска в запущенный экземпляр.
- Настройка поведения (например, «разрешить несколько экземпляров»).

## Decisions

1. **`tauri-plugin-single-instance`, а не собственный IPC.** Плагин официальный,
   кроссплатформенный и использует нативные механизмы ОС (перехват запуска
   процесса). Альтернативы: реализация сокета/lock-файла вручную — лишний
   код и платформенные нюансы (демон, AppArmor, автозапуск); отказ от второго
   процесса в пользу проверки окна — не работает, второй процесс уже создан.

2. **Колбэк переиспользует `tray.rs::show_main_window`.** Функция станет
   `pub(crate)`; логика показа/фокуса не дублируется. Сейчас она приватная и
   используется из клика по трею и пунктов меню.

3. **Плагин регистрируется первым в цепочке `.plugin(...)`.** Он перехватывает
   запуск до инициализации остальных плагинов и окна; иначе второй процесс
   успеет создать лишние ресурсы.

4. **Зависимость только для десктопных платформ.** Плагин добавляется в
   секцию `[target.'cfg(not(any(target_os = "android", target_os = "ios")))'.dependencies]`
   рядом с `tauri-plugin-global-shortcut`; мобильные платформы сборку не ломает.

5. **Разрешения (capabilities) не меняются.** Плагин работает целиком на
   Rust-стороне и не добавляет JS-команд, поэтому правки
   `capabilities/*.json` и `permissions/desktop-tray.toml` не требуются.

## Risks / Trade-offs

- [Плагин использует локальный сокет/IPC] → Второй экземпляр завершается после
  передачи запуска; в dev-режиме (`tauri dev`) поведение может отличаться —
  проверяется вручную.
- [Второй экземпляр на другой платформе/рантайме может не перехватиться] →
  Критерии приёмки проверяются на текущей платформе разработки (Linux);
  поведение на Windows/macOS определяется плагином.
- [Зависимость добавляется в `Cargo.lock`] → Блокировка отсутствует, обновление
  выполняется при сборке; отдельного обновления lock-файла вручную не требуется.
